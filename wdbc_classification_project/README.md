# Project Title

### WDBC CLASSIFICATION AND VISUALIZE

# Project purpose

### This project is for classify the WDBC data with various classification models and visualize the result. 

# Dataset used

### WDBC data was used for this project. And I downloaded that data from sklearn datasets

# How to install requirements

### Onlything you have to do is run !pip install -r requirements.txt

# How to run the code

### After installed the requirements.txt run python wdbc_classification.py

# Output files

### wdbc_classification.py will make 2files. Which is confusion_matrix.png, scatter_plot.png. 

### The code outputs the dataset shape, target names, feature names, accuracy, precision, and recall of the classification models. It also identifies the best model and displays its confusion matrix.

# Best classifier result

### The best classifier results are Decision Tree and Random Forest. Both scored the 1 in accuracy.
